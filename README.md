# 4SightAI Network

Interactive mock of the 4SightAI Network home: Learn AI. Build Trust. Connect the Future.

You are signed in as **Angelo Smith** (Founder). Data stays in this browser.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:43147](http://localhost:43147).

```bash
npm run build
npm start
```

Use `npm start` if a preview proxy blocks Turbopack chunk URLs from `next dev`.
